Layer 1: Replit Autoscale Cold Start (503) When the server is sleeping (scaled to zero), ALL requests — GET, POST, OPTIONS — return 503 with no CORS headers. Layer 2: OPTIONS Preflight Blocked by Replit Proxy Even when the server is confirmed running (verified via same-origin health check), the OPTIONS preflight request still returns 503. Layer 3: The CORS config itself Your app.use(cors()) with default wildcard origin would also fail for credentialed sendBeacon requests, but we can't even see this issue because Layers 1-2 block all traffic before it reaches Express.
